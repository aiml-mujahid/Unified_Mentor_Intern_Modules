# NumPy Practice – Module 1 Worksheet

## About the Project

This repository contains my completed Module 1 worksheet on **NumPy**, a Python library used for numerical computing and array operations.

The Jupyter Notebook demonstrates basic NumPy operations, matrix calculations, and mathematical functions through practical examples.

## Topics Covered

- Creating NumPy arrays
- Reshaping arrays
- Array addition, subtraction, and multiplication
- Scalar and element-wise operations
- Matrix multiplication
- Vector transpose and dot product
- Matrix inverse and identity matrix
- NumPy universal functions (ufuncs), including `sqrt()`, `abs()`, `cos()`, and `log()`

## Technologies Used

- **Language:** Python
- **Library:** NumPy
- **Notebook:** Jupyter Notebook (`.ipynb`)

## How to Run

1. Clone or download this repository.
2. Install Python if it is not already installed.
3. Install NumPy by running:

   ```bash
   pip install numpy
   ```

4. Open the notebook using Jupyter Notebook or Google Colab.
5. Run the cells to explore the examples.
