NumPy Practice – Module 1 Worksheet

About the Project

This repository contains my completed Module 1 worksheet on NumPy, a Python library used for numerical computing and array operations.

The notebook demonstrates basic NumPy operations, matrix calculations, and mathematical functions through practical examples.

Topics Covered

Creating NumPy arrays

Reshaping arrays

Array addition, subtraction, and multiplication

Scalar and element-wise operations

Matrix multiplication

Vector transpose and dot product

Matrix inverse and identity matrix

NumPy universal functions (ufuncs), including sqrt(), abs(), cos(), and log()

Technologies Used

Language: Python

Library: NumPy

Notebook: Jupyter Notebook (.ipynb)

How to Run

Clone or download this repository.

Install Python if it is not already installed.

Install NumPy:

pip install numpy

Open the notebook using Jupyter Notebook or Google Colab.

Run the cells to explore the examples.
